# YourCarYourWay App

Clone project:

> git clone https://github.com/Shikizzz/ChatApp.git

## Front-end 

Go inside the frontend folder:

> cd frontend

Install dependencies:

> npm install

Launch Front-end:

> npm run start;


## Back-end

Install dependencies:

> mvn clean install

Launch Back-end:

>  mvn spring-boot:run
